# 9588 固件配置

9588-jz4740.json 保存已独立核对的 C200 / JZ4740 绑定。verified 标志表示静态固件证据，不表示真机验收通过。profile-template.json 仅为不可构建的格式示例，不是受支持的固件配置。

可用配置必须明确 target=9588、soc=JZ4740、verified=true，写明固件版本、SHA256、长度和加载基址，以及 SDRAM 边界、源码使用的全部 FW_* 宏和非空 CRC 守卫。未把 9688 私有配置作为 9588 地址使用。

公开 9588 SDK 确认 BDA 入口为 0x81c00020，动态服务表头基址为 0x81c00000；私有 RTOS、USB、LCD 等绑定均需对应固件的独立证据。
